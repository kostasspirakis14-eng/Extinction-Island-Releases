# Extinction Island

A 2D co-op dinosaur survival game. You are shipwrecked on an island full of dinosaurs: gather, build, tame, ride and survive, alone or with friends.

## Download

1. Open the [latest release](https://github.com/kostasspirakis14-eng/Extinction-Island-Releases/releases/latest).
2. Under **Assets**, download the `.zip`.
3. Unzip it into a folder of your own (for example Documents) and run the `.exe`.

Windows may warn you about an unknown app the first time. Press **More info**, then **Run anyway**.

## Updates

From version 0.12.12 on, the game checks for a new version every time it starts and asks if you want to update. One click downloads it, and the game opens again in the new version. Your saves stay where they are.
